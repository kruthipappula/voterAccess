# VoterAccess

VoterAccess is an AI-powered web application designed to make California ballot propositions easier to understand, especially for first-time voters and non-native English speakers.

The application provides simplified summaries of ballot propositions and helps users locate nearby polling places.

## Features

- AI-generated summaries of California ballot propositions
- Simplified explanations designed for accessibility
- Google Maps integration for locating nearby polling places
- Interactive web interface
- Chatbot-based user experience
- Responsive HTML/CSS/JavaScript frontend
